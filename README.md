# זכוכית – לאנצ'ר בעברית בסגנון iOS

כל דחיפה ל-`main` בונה אוטומטית קובץ `GlassLauncher.apk` ומפרסמת אותו בעמוד ה-Releases תחת "latest".

## התקנה
1. מורידים את `GlassLauncher.apk` מעמוד ה-Releases ומתקינים (מאשרים "התקנה ממקורות לא ידועים").
2. פותחים את "זכוכית" ← לחיצה ארוכה על מקום ריק ← הגדרות הלאנצ'ר.
3. בחלק "הכנה" מאשרים את כל הסעיפים.
   - שירות הנעילה: אם הכפתור אפור, הגדרות ← אפליקציות ← זכוכית ← ⋮ ← "התרת הגדרות מוגבלות".

## מחוות
- החלקה למטה: חיפוש. החלקה למטה מצד ימין למעלה: מרכז שליטה.
- הקשה כפולה על מקום ריק: Gemini.
- לחיצה ארוכה על מקום ריק: עריכה, טפט, הגדרות.
- בספרייה: גלילה עד הסוף והחזקה של 3 שניות בתחתית – תיקיות נסתרות.
